# C-4
*A mouldable plastic explosive so stable soldiers used it as cooking fuel.*

## At a glance
| Property | Value |
|---|---|
| Composition | ≈91 % RDX, ≈5.3 % plasticiser, ≈2.1 % polyisobutylene binder, ≈1.6 % oil |
| Density | ≈1720 kg/m³ |
| Detonation velocity | ≈8000 m/s |
| Relative effectiveness | ≈1.34× TNT |

## In the real world
C-4 is RDX (one of the most powerful common explosives) bound into a putty you can mould by hand. It is famously insensitive: it can be shot, dropped or burned without detonating. Only a detonator's shock sets it off.

**Uses:** Military demolition, cutting charges.

**Hazards:** Burning it releases toxic fumes; detonates violently with a blasting cap.

## In Ignis
- Burns if lit (ignites **≈660 K**). Needs the strongest shock of all to detonate: **≈30 atm**.
- Placeable solid, shaped however you draw it.
