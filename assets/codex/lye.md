# Lye (NaOH solution)
*Caustic soda dissolved in water: a strong base that eats aluminium.*

## At a glance
| Property | Value |
|---|---|
| Formula | NaOH (aq) |
| Solid density | 2130 kg/m³ |
| 50 % solution density | ≈1520 kg/m³ |
| pH | ≈14 (1 M) |
| Heat of solution | ≈-44.5 kJ/mol (dissolving it gets hot) |

## In the real world
Sodium hydroxide is the base made alongside chlorine in the chlor-alkali process. It turns fats into soap (saponification) and grease into soluble soap in drains. Aluminium dissolves in it, giving off hydrogen, which is how some drain cleaners fizz.

**Uses:** Soap, paper pulping, aluminium refining (Bayer process), drain cleaner, food (pretzels, olives).

**Hazards:** Causes deep chemical burns, especially to eyes. Never mix with acids in a sealed container.

## In Ignis
- Formed when [[sodium]] or [[potassium]] react with water.
- Neutralises [[hydrochloric_acid]] into [[brine]] with heat.
- Dissolves [[aluminium_powder]], releasing hydrogen.

## Recipes
- Lye + [[hydrochloric_acid]] → [[brine]] ([[neutralisation]]).
- Lye + [[aluminium_powder]] → hydrogen.

## Try this
Drop aluminium powder into a lye pool inside a closed box with an igniter on top. Wait for the hydrogen to build up.
